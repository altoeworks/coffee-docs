# Not Just Coffee: Guides for the Curious, Confused & Caffeinated

Welcome! 👋  
This repo is the home of **[coffee.altoeworks.net](https://coffee.altoeworks.net)**—a simple, self-built website dedicated to making coffee more understandable, approachable, and deeply enjoyable.

## 📚 What's Inside

Two comprehensive, visual-first guides on coffee—written for both newcomers and curious nerds alike:

### 1. **The Anatomy of Coffee Flavor**  
A foundational deep dive into how coffee tastes the way it does. Covers everything from varieties and processing to roast, water, and brewing.  
👉 [Read or download](https://coffee.altoeworks.net#anatomy-guide)

### 2. **Under Pressure**  
A detailed espresso guide focused on technique, variables, and troubleshooting—from puck prep and flow profiling to weird shots and workflow fixes.  
👉 [Read or download](https://coffee.altoeworks.net#espresso-guide)

### 3. **Interactive Coffee Glossary**  
A comprehensive, searchable reference covering coffee terminology from "extraction" to "terroir," "crema" to "cupping." Filter by category or browse alphabetically.  
👉 [Explore the glossary](https://coffee.altoeworks.net/glossary.html)

## 🌐 Live Website  
The site is live at **[coffee.altoeworks.net](https://coffee.altoeworks.net)**  
It's: 
- Fast, responsive, and mobile-friendly  
- Dark mode included with smooth transitions
- Interactive glossary with search and category filtering
- Progress bars and smooth scrolling animations
- Social sharing functionality
- Fully free and open for sharing

## ✍️ Why This Exists

I got curious about coffee—and never really stopped.  
These guides started as notes to help me understand what I was tasting, why shots failed, and how to get better results without the guesswork. Over time, those notes turned into something deeper, and I realized others might be on the same path. So I made the thing I wish I'd had when I started.

If they help you enjoy your coffee more—that's all I could ask for.

## 🛠️ Technical Details

- **Frontend**: Vanilla HTML, TailwindCSS, JavaScript
- **Build Process**: TailwindCSS compilation
- **Styling**: Custom color palette with dark mode support
- **Fonts**: Inter variable font family
- **Icons**: FontAwesome for UI elements
- **Responsive**: Mobile-first design with hamburger navigation
- **Performance**: Optimized CSS, minimal JavaScript, fast loading

To run this locally:

```bash
# Install dependencies
npm install

# Start development server with CSS watching
npm run watch

# Build for production
npm run build

# Serve locally
npm run serve
```
